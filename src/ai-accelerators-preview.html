Why compare computing stacks?

AI performance cannot be reduced to a chip specification. Numerical behaviour, preprocessing, frameworks, operator implementations, memory, batch size and deployment tooling all affect the observed result.

GPU compute stack

NVIDIA RTX 4090

A CUDA-capable GPU used as a reference for PyTorch training and for a separate MindSpore GPU execution path. Comparing both frameworks on the same accelerator helps expose software overhead.

Hardware class: consumer-grade GPU — a high-end gaming and workstation part, not designed for data-centre or industrial deployment.

CUDAPyTorchMindSpore GPU
NPU compute stack

Ascend 910C

An AI accelerator assessed with MindSpore and CANN for ResNet-50, and with torch-npu for Qwen2 inference. The experiments investigate whether trained behaviour transfers and how throughput scales.

Hardware class: data-centre-class AI processor — server-grade silicon built for scale-out data-centre deployment, not a consumer device.

The experimental design

A controlled ResNet-50 transfer-learning task on 1,000 NIH Chest X-ray images. The backbone was frozen while a 10-class classification head was trained.

The goal is reproducible comparison under one deliberately constrained protocol, not clinical diagnostic performance benchmarking. An accuracy of 20.33% is modest and should not be mistaken for a clinically useful classifier.

Training equivalence

With shared starting weights and controlled data ordering, all three configurations reached the same best validation accuracy at epoch 8. Loss values were also closely aligned.

What the parity work revealed

The most valuable engineering insights came from eliminating mismatches that could otherwise look like hardware differences.

01 / Weights

Same starting point

The torchvision checkpoint was mapped into MindSpore naming with full 267/267 parameter coverage. Independently initialised or separately trained checkpoints would not make a clean comparison.

02 / Operators

Small semantics, real effects

TF32 settings, pooling padding, global average pooling and batch-normalisation momentum needed attention. One batch-statistics difference remained documented.

03 / Execution

The pipeline matters

Removing PIL decoding from the timed path changed the measured throughput profile, reinforcing the distinction between end-to-end runtime and cached compute throughput.

Beyond computer vision: Qwen2 inference

A second cross-stack check used Qwen2-1.5B-Instruct, a common checkpoint, 16 prompts, greedy decoding, 48 generated tokens and FP32 across all legs.

From training to deployment

Verified

Fine-tuning and export

Fine-tuning with ResNet-50 layer4 and the classifier unfrozen ran end-to-end on the Ascend 910C. Model export produced MindIR, AIR and ONNX artefacts.

  • Five-epoch fine-tuning confirmed on the 910C
  • Checkpoint compatibility checked across MindSpore versions
  • Three export formats produced
Unresolved deployment step

Offline .om compilation

Final compilation using atc was not completed with the available toolchain combination. The benchmark records MindIR protobuf parsing failure, AIR operator placement failure and ONNX AICore pre-compilation failure.

A reproducible record should distinguish successful model export from a successfully compiled and executed deployment artefact.

Key takeaway

Comparable model behaviour does not imply comparable runtime, and comparable runtime does not guarantee deployability.

A useful accelerator evaluation needs three layers of evidence: model equivalence, workload-specific performance and the ability to export, compile and execute the intended deployment format.

Source and scope

This page documents the Cross-Stack Transfer-Learning Benchmark: NVIDIA vs. Ascend (November 2026). Figures are taken from the benchmark’s recorded experiments rather than general vendor specifications.

For scientific transparency: the benchmark’s highest ResNet-50 validation accuracy was 0.2033 on a 300-image validation set. The results are a cross-stack methods benchmark, not a clinical performance claim.
